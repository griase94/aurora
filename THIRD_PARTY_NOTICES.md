# Third-party notices

Aurora's own code is licensed under AGPL-3.0-only (see [LICENSE](LICENSE)). The packages also ship
material created by others under its own licence. Each entry names the material, where it ships, its
source, its licence and the notice the licence requires.

Development-only dependencies (build tools, test runners) are not shipped in any package and are not
listed here; `pnpm licenses list --prod` shows the runtime dependency tree of a package.

## Shipped material

None yet. The kit import adds the entries; each one uses this form:

### <Name of the material>

- **Ships in:** `<package>` (`<path inside the package>`)
- **Source:** <where it comes from, with version or date>
- **Licence:** <SPDX id> (<link to the licence text>)
- **Notice:** <the copyright line or attribution the licence requires, verbatim>
- **Changes:** <what Aurora changed, or "none">
