# Sources

Opened on 2026-11-12. Rules marked "repository evidence" come from measurements on the Atlas itself
(audit 2026-11-12 and the stage-runtime review rounds, 2026-11-13), not from an external source.

| Rule | Source |
|---|---|
| Iframe resize is the faithful viewport model; media queries, viewport units and `fixed` follow the frame | Storybook viewport addon: https://github.com/storybookjs/storybook/pull/1753 ; https://storybook.js.org/addons/storybook-addon-viewport-resizer ; https://storybook.js.org/addons/storybook-addon-multi-preview |
| Container queries respond to an ancestor, media queries only to the viewport | https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_containment/Container_queries |
| One iframe per width, a frame wrapper for providers and themes | Playroom README: https://github.com/seek-oss/playroom |
| A lazy iframe on a dedicated preview route | shadcn/ui block viewer: https://github.com/shadcn-ui/ui/blob/main/apps/v4/components/block-viewer.tsx |
| `loading="lazy"` on offscreen iframes; browser-defined distance | https://web.dev/articles/iframe-lazy-loading |
| Chromium loads lazy iframes far ahead, Mobile Safari only in view (single data point) | https://github.com/storybookjs/vitest-plugin-rsc/pull/194 |
| `content-visibility` and `contain-intrinsic-size`; avoid forcing layout on skipped subtrees | https://web.dev/articles/content-visibility |
| CSS containment values (check the `contain` reference page before relying on a value) | https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_containment |
| Read layout, then write; no layout thrashing | https://web.dev/articles/avoid-large-complex-layouts-and-layout-thrashing |
| Core Web Vitals "good": LCP ≤ 2.5 s, INP ≤ 200 ms, CLS ≤ 0.1 (p75) | https://web.dev/articles/vitals |
| `pointer-events: none` on frames while dragging | practitioner tactic, no primary source found (unverified) |
| Whole-document restyle from broad `:has()` rules on insertion; one mount per task multiplies it; `content-visibility` made the wall worse | repository evidence: CDP traces with invalidation tracking and a CSSOM bisection of the `:has()` rules on the wall |
| Single benchmark runs mislead | repository evidence: one baseline run contained a 34 s stall that two re-runs did not reproduce |
| Text below 75 % scale reads as broken; layout jumps on toggles | repository evidence: design and runtime audits of the stage at 768 and in the Light-and-Dark split |
| Class names built from parts are not generated by Tailwind | https://tailwindcss.com/docs/detecting-classes-in-source-files (dynamic class names) |
